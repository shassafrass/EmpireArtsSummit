# EmpireArtsSummit
Empire Arts Summit
EMPIRE ARTS SUMMIT — CONTACT PAGE

Upload index.html and all three .vcf files to the ROOT of your GitHub repository (not the zip).
In repository Settings > Pages, select Deploy from a branch, main, /(root).
Your page will be at https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
The logo is embedded in index.html, so no separate image upload is required.

Test the three ADD TO CONTACTS buttons on a phone after publishing. Some phones download a .vcf first and require tapping it in Downloads/Files to import.
